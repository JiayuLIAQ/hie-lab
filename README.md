# Healthy and Intelligent Environments (HiE) Lab at NUS

Public website for the HiE Lab, led by Jiayu Li in the Department of the Built Environment, National University of Singapore.

**Website:** https://jiayuliaq.github.io/hie-lab/

**Contact:** jy.li@nus.edu.sg

## Website

The site is buildless HTML, CSS and JavaScript. GitHub Pages publishes `main` → `/docs`.

- `docs/index.html`: lab homepage, research, people, projects and publications.
- `docs/people/jiayu-li.html`: director profile.
- `docs/style.css` and `docs/main.js`: presentation and interactions.
- `docs/assets/`: logos, illustration, portraits and locally served fonts.
- `docs/sitemap.xml`: public page URLs.

Preview with `python3 -m http.server 8000 --directory docs`.

The former https://jiayuliaq.github.io/trace-lab/ redirects here. Internal positioning documents and design drafts are not included in this repository.
